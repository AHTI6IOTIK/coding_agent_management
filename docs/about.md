# О проекте

## Стек и назначение

Сервис написан на Go 1.26. HTTP-слой построен на Echo, для подключения SQLite используется `database/sql`, метрики отдаёт Prometheus, а browser e2e выполняет Playwright. Калькулятор на `/calculator` отправляет выражение в `POST /echo` и показывает полученный результат.

## Ограничение по путям

Плагин `protect-files` запрещает изменение `.env`, файлов внутри `.git` и lock-файлов до выполнения записи. Это проверено попыткой добавить `BAR=BAZ` в `.env`: операция заблокирована, а значение не записано.
