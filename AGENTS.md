# Галерея изображений

- Модуль требует Go 1.26 (`go.mod`). Точка входа сервиса — `cmd/server`; HTTP-маршруты — `internal/httpserver`; загрузка конфигурации — `internal/config`.
- Настройки берутся только из окружения: `APP_PORT` (8080), `DB_PATH` (`gallery.db`), `METRICS_PORT` (9090), `PPROF_PORT` (6060). Метрики и pprof намеренно слушают только `127.0.0.1`.

## Проверки

```sh
go test --race ./...
golangci-lint run ./...
```

- Для проверки HTTP-пакета: `go test --race ./internal/httpserver`.
- Юнит-тесты размещайте рядом с кодом в `*_test.go`.
- Функциональные и интеграционные тесты размещайте в `tests/`; интеграционные тесты запускайте через testcontainers.
- Тесты с БД должны явно проверять ожидаемые изменения данных, а не только HTTP-статус или отсутствие ошибки.

## Конвенции Go

- Форматируйте код через `gofmt`; перед завершением выполняйте `go vet` и `golangci-lint` в пределах согласованного объёма.
- Используйте идиоматичные имена пакетов и экспортов; не добавляйте абстракции и зависимости без необходимости и согласования.
- Обрабатывайте каждую ошибку; при передаче причины выше оборачивайте её через `%w`.
- Для операций с отменой или таймаутом передавайте `context.Context` первым параметром.
- Для наборов сценариев используйте table-driven тесты.

## Правила работы

- Создавайте ветки `feature/<задача>`, `fix/<задача>` или `chore/<задача>`; не коммитьте напрямую в `main`.
- Используйте Conventional Commits; один коммит должен содержать один логически завершённый пакет изменений.
- Не выполняйте commit или push без явного запроса пользователя.
- Не изменяйте `.env`, `.git` и lock-файлы без отдельного подтверждения.
- До изменений согласуйте план; после изменений выполните релевантные проверки и зафиксируйте их результат.

## Изменения

- До любых правок прочитайте и соблюдайте [`.agents/rules/README.md`](.agents/rules/README.md): он требует согласовать план, а для продуктовых изменений — baseline и TDD.
- При нетривиальной логике, HTTP-контрактах, валидации, обработке ошибок или доступе к данным применяйте навык [`write-tests`](.agents/skills/write-tests/SKILL.md).
