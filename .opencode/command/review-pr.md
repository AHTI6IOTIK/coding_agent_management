---
description: Проверяет изменения относительно указанной базы без изменения файлов.
---

Выполни только code review изменений относительно `$ARGUMENTS`. Если база не указана, запроси её у пользователя.

Проверь корректность, безопасность, обработку ошибок, тесты и соответствие правилам проекта. Не изменяй файлы, не выполняй commit, push или другие операции с побочным эффектом.

Для каждого замечания укажи приоритет, файл, строку или участок кода, риск и рекомендуемое исправление. Если замечаний нет, явно сообщи об этом и назови непроверенные области.
