# Написание тестов

1. Прочитайте затронутый код, его вызывающие места, существующие тесты и применимые правила из `.agents/rules/`.
2. Определите наблюдаемое поведение, граничные случаи, ошибки и требования безопасности.
3. Добавьте минимальные тесты, которые проверяют новое или изменённое поведение. Не меняйте продуктовый код только ради прохождения существующего теста.
4. Для HTTP-обработчиков проверьте успешный ответ, ошибки валидации и отсутствие раскрытия чувствительных данных.
5. Выполните `go test --race ./...`; выполните `golangci-lint run ./...`, если конфигурация линтера работоспособна.
6. Если проверка не проходит, зафиксируйте причину и примените `.agents/rules/testing.md`. Не расширяйте объём исправления без согласования.

Навык не даёт права изменять файлы без согласованного плана.
