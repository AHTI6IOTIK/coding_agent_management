# Автоматически применяемые навыки

| Навык | Когда применять |
| --- | --- |
| [write-tests](write-tests/SKILL.md) | При добавлении или изменении нетривиальной логики, HTTP-контрактов, обработки ошибок, валидации или доступа к данным. |

Навык не заменяет правила из `AGENTS.md` и `.agents/rules/`: перед изменением файлов агент обязан подготовить и согласовать план.
