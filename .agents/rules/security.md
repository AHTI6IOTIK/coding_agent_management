# Безопасность данных

Используйте эти правила при реализации функциональности, добавлении или изменении логирования, а также написании или изменении тестов.

- Неавторизованному клиенту можно возвращать только явно публичные данные.
- Чувствительные данные можно возвращать только аутентифицированному субъекту с подтверждённым правом доступа.
- Клиент не должен получать чувствительные данные, принадлежащие другому клиенту.
- Проверяйте аутентификацию и авторизацию на сервере для каждого запроса; проверки в клиентском интерфейсе недостаточно.
- Если аутентификация, право доступа или принадлежность данных не подтверждены однозначно, отказывайте в доступе без раскрытия чувствительных данных.
- При реализации функциональности проверяйте, что чувствительные данные не попадают в ответы API.
- При добавлении или изменении логирования проверяйте, что чувствительные данные не попадают в логи.
- При написании или изменении тестов проверяйте сценарии неавторизованного доступа и доступа к данным другого клиента.
